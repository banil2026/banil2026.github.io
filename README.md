# Anil Kumar Reddy — Data Analyst Portfolio

This is a GitHub Pages-ready static portfolio.

## Publish it free with GitHub Pages

1. Create a GitHub repository named `anil-kumar-portfolio` (or any name).
2. Upload `index.html`, `styles.css`, `script.js`, and `resume.pdf`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide your public portfolio URL.

Typical URL:
`https://banil2026.github.io/anil-kumar-portfolio/`

If your repository has a different name, replace the final path accordingly.
